# 1. 달라진 워크스페이스

현재 개발 중인 School King은 하나의 게임 안에 로비와 두 개의 경기장이 각각 별도 플레이스(Place)로 구성되어 있습니다. 각 플레이스는 맵·스크립트·UI를 가진 독립적인 Studio 작업 공간입니다.

게임 전체 ID(GameId/UniverseId)는 `10769319354`입니다.

| 구분 | Studio에 표시되는 이름 | 역할 | PlaceId |
|---|---|---|---|
| 로비 | [TEST] 스쿨 킹 로비 | 최초 접속, 파티 구성, 모드 선택·매칭, 경기 후 복귀 | 92428207409677 |
| 왕관 뺏기 | [테스트] TGS - 크라운 | 왕관 뺏기 경기 진행 | 79880636827328 |
| 테니스장 | [테스트] 테니스 - 1v1 | 1대1 경기 진행 | 116907065195895 |

플레이어의 기본 이동 흐름은 **게임 접속 → 로비 → 모드 선택·매칭 → 해당 경기장 → 경기 종료 후 로비 복귀**입니다.

플레이스는 편집하는 맵 단위이고, 경기 방은 플레이 중 해당 맵에서 실행되는 서버입니다. 경기 방마다 Studio 작업 파일을 따로 만드는 구조는 아닙니다.

## 작업자가 접속하는 방법

각 작업자는 본인의 Roblox 계정으로 접속하며, 해당 게임의 **편집(Edit) 권한**을 먼저 받아야 합니다. 현재 확인한 소유 유형은 개인 소유입니다. 소유자가 Studio의 Collaborate에서 작업자를 추가하고 Edit 권한을 지정할 수 있습니다. 권한이 있는 작업자는 Team Create로 함께 편집할 수 있습니다. [Roblox 공동 작업 안내](https://create.roblox.com/docs/projects/collaboration).

1. 본인 계정으로 [Creator Dashboard](https://create.roblox.com/dashboard/creations)에 접속합니다.
2. **나와 공유됨(Shared With Me)**에서 해당 프로젝트를 찾습니다. 소유자는 자신의 제작 목록에서 찾습니다.
3. 프로젝트의 **Configurations → Places**로 이동합니다.
4. 위 표에서 담당할 플레이스를 찾아 **Edit in Studio**를 선택합니다.
5. Studio가 열리면 플레이스 이름을 확인하고 편집합니다.

플레이스별 Edit in Studio 경로는 [Roblox 플레이스 관리 안내](https://create.roblox.com/docs/production/publishing/publish-games-and-places#change-start-place)에 설명되어 있습니다. 해당 안내의 시작 장소 교체·덮어쓰기 단계는 이 작업에 필요하지 않습니다.

프로젝트 링크를 전달할 때는 편집 권한도 함께 설정해야 합니다. 작업자마다 본인 계정으로 접근하므로 소유자 계정에 로그인할 필요는 없습니다.

## 왕관 뺏기와 테니스장 편집 화면 열기

### 왕관 뺏기(TGS)

1. Creator Dashboard에서 편집 권한을 받은 School King 게임을 엽니다.
2. **Configurations → Places**로 이동합니다.
3. **[테스트] TGS - 크라운**을 찾습니다. PlaceId는 `79880636827328`입니다.
4. 해당 플레이스의 **Edit in Studio**를 선택합니다.
5. Studio에 왕관 뺏기 맵이 열리면 작업합니다.

### 테니스장(1대1)

1. 같은 School King 게임의 **Configurations → Places**로 이동합니다.
2. **[테스트] 테니스 - 1v1**을 찾습니다. PlaceId는 `116907065195895`입니다.
3. 해당 플레이스의 **Edit in Studio**를 선택합니다.
4. Studio에 테니스장 맵이 열리면 작업합니다.

로비를 열어도 두 경기장의 편집 화면이 함께 열리지는 않습니다. 담당 경기장을 Places 목록에서 별도로 열어야 합니다. 웹페이지는 플레이스를 찾아 Studio를 여는 접속 경로이고, 실제 맵·코드 편집은 Studio에서 진행합니다.

[공식 플레이스별 Studio 열기 안내](https://create.roblox.com/docs/production/publishing/publish-games-and-places#change-start-place).

## 실제 게임에 들어가서 테스트하기

Roblox에서 로비에 접속한 뒤 원하는 모드(왕관 뺏기 또는 1대1 테니스장)를 선택하고, 매칭·입장 절차를 통해 경기장으로 이동합니다. 이는 플레이스 편집 화면을 여는 것과 별개입니다.

경기장 내부 기능은 해당 플레이스를 Studio에서 열어 테스트할 수 있습니다. 로비에서 경기장으로 이동하거나 경기 종료 후 로비로 복귀하는 전체 흐름은 게시된 버전의 Roblox 클라이언트에서 확인합니다. TeleportService는 Studio 플레이 테스트에서 실제 이동을 지원하지 않습니다. [공식 텔레포트 테스트 안내](https://create.roblox.com/docs/projects/teleport).

## 작업 대상을 고르는 기준

- 로비 화면·파티·모드 선택·매칭 관련 작업 → 로비 플레이스.
- 왕관 뺏기 맵·모드 규칙 관련 작업 → TGS 플레이스.
- 테니스장 맵·1대1 규칙 관련 작업 → 테니스 플레이스.
- 여러 모드에서 사용하는 무기·전투 HUD·회복·이동 기능 → 적용 대상 플레이스 모두 확인.

각 플레이스의 코드와 맵은 별도로 관리됩니다. 한 곳의 수정이 다른 플레이스에 자동 반영된다고 가정하면 안 됩니다. 공통 기능을 수정할 때는 반영해야 할 장소와 실제 반영 여부를 함께 기록합니다.

편집 저장과 서비스 반영을 구분하고, Roblox 게시는 프로젝트 소유자가 진행합니다. 로비와 경기장 사이의 실제 이동은 게시된 게임의 Roblox 클라이언트에서 확인합니다. [Roblox 텔레포트 테스트 제한](https://create.roblox.com/docs/projects/teleport).

## 확인 범위

2026-10-17 연결된 Studio의 플레이스 이름·ID, 로비 IntegrationConfig의 게임 ID/목적지 및 소유 유형을 읽어 확인했습니다. 실제 공동 작업자의 권한이나 계정별 대시보드 접근 성공 여부는 확인하지 않았습니다. 안내 문서만 작성했으며 게임 코드·권한·게시 상태를 변경하지 않았습니다.

신규 무기·신규 모드·부착물 기획은 이 문서에 추가하지 않았으며 별도 내용 확정 후 작성합니다.
