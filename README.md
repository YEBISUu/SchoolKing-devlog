## 작업 영역

| 영역 | 역할 | 기록상 상태 |
|---|---|---|
| TGS 원본 | 왕관 뺏기 | 공통 이동·무기 수정 기록 있음 |
| 테니스장 원본 | 1대1 및 봇 연습 | 라운드·봇·연출 개발 기록 있음 |
| 통합 테스트 로비 | 모드 선택, 파티, 진행 중 경기 관전 | 별도 테스트 게임에 구성 |
| 통합 테스트 경기 사본 | 로비에서 입장하는 TGS/테니스 | 기존 매칭과 새 매칭 충돌 방지 처리 |

로비 통합은 원본과 분리한 사본에서 진행했습니다. 앞선 원본 공통 패치와 사본에만 적용한 로비·파티 패치를 구분합니다.

## 상태 읽는 법

- **적용 확인:** 당시 소스 또는 저장된 검증 자료로 확인.
- **분리 검증:** 규칙·함수 테스트이며 온라인 다인 플레이 통과를 뜻하지 않음.
- **Studio 검증:** Studio 실행/테스트 클라이언트 확인.
- **실기 관찰:** Roblox 앱 플레이 관찰 기록 있음.
- **게시 기록:** 당시 게시 확인 자료 있음. 현재 최신 배포와 동일하다는 보장은 없음.

Roblox 게시는 개발자가 직접 진행합니다. 이 저장소에는 문서만 올리며 플레이스 백업·원시 로그·접속 비밀값은 별도 보관합니다.
