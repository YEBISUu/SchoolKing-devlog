# 2026-10-18 — 신규 무기 기획 초안과 대걸레 저격총 이미지

## 상태

사용자가 제시한 신규 무기 아이디어를 정리하고 대걸레 저격총의 1차 컨셉 이미지를 생성했다. 신규 무기 전체의 구현이나 최종 디자인 확정을 의미하지 않는다. 이번 작업에서 게임 코드·Studio·Roblox 게시 상태는 변경하지 않았다.

## 사용자 기획

| 무기 | 핵심 아이디어 | 미확정·구분 사항 |
|---|---|---|
| 코드 | 유선 청소기의 자동 회수 코드. 패스파인더 계열 그래플 이동, 그랩, 채찍처럼 휘두르는 공격. 이동기가 있는 대신 짧은 공격 사거리. | 상세 수치와 그랩 규칙 미확정. |
| 약병 샷건 | 약을 흩뿌리는 펌프 액션 샷건. 지속 피해(도트 대미지) 포함. | 지속 시간·피해량 등 미확정. |
| 대걸레 저격총 | 철제 대걸레 봉 총신, 테이프로 고정한 망원경, 볼트 액션, 크레파스 탄. 압축하면 무지개 크레파스. 뒤쪽 가스탱크의 압력으로 발사하는 설정. | 기존 스나이퍼의 외형 기획. 손잡이·개머리판은 검토 중이며 가스 발사는 설정안. |
| 철자 석궁 | 학용품을 조잡하게 조립한 석궁. 필기구를 화살로 사용. 직접 피해용·지속 피해용·벽꿍용의 3종 선택. | 지속 피해용 필기구는 만년필 후보. 벽꿍 조건·효과 수치 미확정. |
| 카메라 | 사용자 별도 설명·스케치 참고 대상. | 현재 텍스트만으로 상세 기능을 확정하지 않음. |
| 대형 청소기 | 본체를 등에 멤. 조준 기능 없음. 좌클릭 흩뿌리기 기본 공격 또는 흡수·축적한 것을 사용하는 공격. 우클릭 범위 내 공격 흡수·저장. 방어 기능 대신 낮은 기동성. | 좌클릭 상세 방식과 흡수 가능 공격·저장량 미확정. |

## 대걸레 저격총 1차 컨셉

- 내장 이미지 생성 도구로 새 컨셉 이미지 1장을 생성했다.
- 전체 옆모습에 긴 철제 대걸레 봉, 테이프로 고정한 망원경, 볼트 손잡이, 후방 가스탱크를 표현했다.
- 일반 크레파스와 무지개 강화 크레파스를 별도 소품으로 배치했다.
- 손잡이·어깨 받침·색상·세부 형태는 시각화 과정의 임시 제안이며 최종 모델 요구사항이 아니다.
- 모델링 논의용 컨셉 이미지이며, 무기 선택용 흰색 UI 아이콘이나 완성된 3D 모델은 아니다.
- 출력 파일명: `mop-sniper-concept-v1.png`. 원본 이미지와 생성 프롬프트는 로컬 프로젝트 산출물로 보관했다. 이 공개 기록에는 이미지를 업로드하지 않았다.

## 검증 및 남은 확인

- 생성 이미지의 주요 소품·전체 실루엣과 두 종류 크레파스 표현을 시각적으로 확인했다.
- 사용자의 디자인 승인, 최종 비율, 손잡이·개머리판 결정, 3D 모델 제작과 인게임 시야·애니메이션 검증은 남아 있다.
- 실제 무기 수치·작동·게임 성능 테스트는 이번 이미지 제작 범위에 포함하지 않았다.
