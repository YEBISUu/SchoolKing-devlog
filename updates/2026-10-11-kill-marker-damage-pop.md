# 빨간 처치 마커와 누적 피해 숫자 반응

[변경 기록](../CHANGELOG.md) · [현재 설정](../CURRENT.md) · [남은 확인](../TODO.md)

2026-10-11. 전체 타격감 개선안 중 사용자 선택에 따라 **처치 표시와 누적 피해 숫자 반응**을 먼저 적용했다. 음원 작업은 보류했으며 이번에는 소리를 변경하지 않았다. TGS·테니스 Studio 편집본 적용, Roblox 미게시.

## 최종 표시

| 항목 | 설정 |
|---|---|
| 일반 명중 | 기존 흰색, 헤드샷 노랑, 총0.18초 |
| 처치 마커 | 빨강 RGB255/60/60, 중앙을 비운 네 방향 대각선 |
| 처치 유지 | 불투명0.20초 + 페이드0.15초 = 총0.35초 |
| 처치 순간 크기 | 기본24×4의1.25배(30×5),0.09초에 기본 크기로 복귀 |
| 처치 우선순위 | 표시 중 일반/헤드샷 명중으로 덮이지 않음. 다음 처치는 새로 시작 |
| 누적 피해 숫자 | 매 명중 UIScale1.22배,0.16초에1배 복귀 |
| 연사/동시 산탄 | 배율 누적 없이 고정1.22배에서 재시작 |

기존 처치 마커는 일반 명중과 같은 페이드 Tween을 사용해 약0.18초에 사라졌다. 단일 갱신 루프가 수명·색·움직임을 관리하도록 바꿔 이전 페이드가 새 명중/처치를 숨기는 경합도 제거했다.

피해 합산 값·좌우 배치·단일 피해 숫자와 헤드샷 색·기존 숫자 수명은 유지한다. 누적 숫자의 가운데를 기준으로 크기를 바꾸며 정수 TextSize 대신 UIScale로 연속적인 크기 변화를 만든다.

편집 위치는 양쪽 `StarterPlayer.StarterPlayerScripts.DamageNumbers`. `KILL_HOLD`, `KILL_FADE`, `KILL_POP_SCALE`, `TOTAL_POP_SCALE`, `TOTAL_POP_TIME` 상수로 조절할 수 있다.

## 테니스 처치 신호 연결

조사 결과 테니스에는 KillMarkerEvent와 수신 UI가 있었지만 실제 서버 처치 귀속 처리에서 이 이벤트를 보내지 않았다. `ServerScriptService.TennisDuelService`의 기존 확정 사망/공격자 귀속 검사 이후, 해당 서버에 남아 있는 인간 처치자에게만 전송하도록 추가했다.

- 플레이어와 연습 봇을 처치했을 때 모두 적용.
- 환경사, 오래된 공격자 기록, 봇이 처치한 경우, 퇴장한 공격자에게는 인간용 마커를 보내지 않음.
- 기존 라운드 epoch/사망 중복 검사와 지연 귀속 확인을 사용한다.
- 점수·사망 통계·기존 슬로모션 처리를 유지한다.
- TGS의 기존 CapturePointSystem 처치 신호는 변경하지 않았다.

## 검증

실제 플레이어/RemoteEvent에 시험 데이터를 보내지 않는 분리 환경에서 UI 전체 코드와 실제 테니스 사망 처리 구간·라운드 규칙을 사용해 **35개 검사 통과**:

- 일반 명중 유지, 빨간 처치/처음 크기/0.35초 수명/후반 페이드.
- 처치 뒤 도착한 일반/헤드샷 명중의 덮어쓰기 차단, 연속 처치 수명 갱신.
- 처치 표시 중에도 피해 합산과 숫자 확대 정상 진행.
- 연사20회·동시 산탄8개의 합산/최대 배율 제한,0.16초 복귀와 기존 만료 정리.
- 플레이어/봇 처치에 마커1회, 통계·슬로모션 호출 보존.
- 중복 사망·환경사·오래된 귀속·봇 처치·퇴장·이전 라운드·이전 캐릭터·지연 처리 중 epoch 변경 제외.

변경3개 소스 컴파일/최종 내용 대조 통과. 실제 UI 복제본을 사용한 테니스 **편집 화면 프리뷰**에서 빨간 마커와 확대된 숫자를 확인한 뒤 임시 객체를 제거했다. 프리뷰의 숫자는 확인용 화면 위치에 배치한 것이며 실제 게임의 월드 피해 숫자 위치는 유지했다.

최종 실제 사용자 입력·온라인 다인전·모바일 체감은 미검증이다. 이번 작업에서 Play 모드의 실제 처치를 새로 검증한 것은 아니다.

## 백업과 복구

양쪽 `ServerStorage.CombatFeedbackVisualBackup_20261011`과 로컬 산출물에 원본을 보관했다. TGS는 DamageNumbers1개, 테니스는 DamageNumbers/TennisDuelService2개다.

로컬 전체 복구 스크립트는 해당 맵의 원본을 복원한다. 이번 작업 후 전체 원복을 실제 실행하지는 않았다. 공개 저장소에는 개발 문서만 반영했으며 게임 소스·원시 로그·백업을 공개하지 않았다.
