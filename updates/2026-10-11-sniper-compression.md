## 탄 수별 합치기와 무지개

| 합치는 탄 수 | 합치기 소요 시간 | 결과 |
|---|---|---|
| 2발 | 1.2초 | 2발 강화탄1발 |
| 3발 | 1.8초 | 3발 강화탄1발 |
| 4발 | 2.4초 | 4발 강화탄1발 |
| 5발 | 기존3초 | 5발 강화탄1발 |

R을0.4초 유지해 합치기에 진입하는 조건은 별도 유지한다. 서버와 클라이언트 애니메이션이 공통 `SniperCompression.Duration` 계산을 사용한다. 기준은 `GunConfig.Sniper.CompressTime × 합치는 탄 수 / MagazineSize`이며 현재3초/5발이다. 피해량·탄창 크기·일반 재장전2.5초는 유지했다.

중앙 잔탄/하단 탄창 숫자의 무지개 한 바퀴는2.4→0.8초, 기존보다3배 빠르게 순환한다. `GunSystem.AmmoWarningStyle.EmpoweredColorPeriod` 속성에서 조정할 수 있다.

## 합치기 게이지

`StarterGui.GameHUD.CompressionGauge`에 합치는 탄 수·남은 시간·민트색 진행 바를 배치했다.

- Position 기본 X Scale0.5/Offset0, Y Scale0.5/Offset150.
- Size 기본240×46. Position/Size를 직접 수정하며 컨트롤러는 두 값을 덮어쓰지 않는다.
- 서버의 CompressFinish/CompressDuration/CompressRounds로 진행률을 표시한다.
- 합치기 취소·완료·무기 해제에서 서버 진행 속성을 비운다. 다른 무기·사망·메뉴·관전·로비·테니스 연출/Frozen에서는 UI를 숨긴다.
- 기존 스코프의 합치기 카운트다운 글씨는 중복 표시하지 않는다. 강화탄 보유 상태 안내와 기존 모바일 버튼은 유지한다.
- Studio에서 프리뷰할 때 Visible을 켤 수 있으며, 실행 중에는 컨트롤러가 상태에 따라 표시한다.

## 최종 사운드

| 용도 | 사용자가 지정한 원본 | 최종 SoundId | 게임 내 편집 위치 |
|---|---|---|---|
| 합치기 완료 | Rainbow - Sound Effect | 88473378930877 | GunSystem.Sounds.Sniper.CompressComplete |
| 강화탄 발사 추가음 | Slash - Rainbowrath Sword | 134856092695680 | GunSystem.Sounds.Sniper.EmpoweredFire |

두 항목은 별도 Sound이다. 최종 등록 기준 음원/길이는 서로 다르다(완료2.256초, 추가 발사 약1.173초). Workspace 원본은 수정하지 않았다.

완료음은 서버가 합치기 완료를 승인한 응답에서 사수에게1회 재생한다. 완료 번호로 중복 응답 재생을 차단하고, 일반 동기화·취소·일반 재장전에는 재생하지 않는다.

강화탄은 기존 총소리와 추가 효과음을 함께 재생한다. 사수에게는 기존 로컬 격발 경로, 다른 플레이어에게는 서버의 소유자 제외 공간음 경로를 사용한다. 일반탄에는 추가음이 없고 서버에서 거절된 발사는 관찰자에게 방송하지 않는다. 로컬 격발음은 기존과 같이 클라이언트 예측 경로다.

## 검증

실제 플레이어/RemoteEvent에 가짜 탄약을 보내지 않는 분리 환경에서 최종 코드의 함수·이벤트 처리·UI 렌더 구간을 실행하여 **74개 검사 통과**:

- 2~5발 서버 소요 시간/시작 상태와 클라이언트 애니메이션 속도 일치.
- 실제 타이머 완료, 강화 수 보존, 취소/해제의 탄약 보존 및 뒤늦은 완료 차단.
- 탄 수별50% 게이지/탄 수 문구,100% 상한, 위치·크기 보존, 비전투/사망/다른 무기의 숨김.
- 완료음 중복 차단·다른 Tool 응답 차단·다음 완료 재생·일반 재장전 제외.
- 강화탄은 기본 격발+추가음, 일반탄은 기본음만, 서버 거절은 추가 방송 없음.
- 강화탄 발사 후0발/강화 해제, 일반 재장전5발/예비25 유지.

양쪽 각6개 최종 소스 컴파일/정확한 대조, 게이지 초기 숨김·음원 ID·백업/임시 검사 정리 확인. 두 음원의 PreloadAsync 성공 및 IsLoaded/길이 확인. 테니스 **편집 화면**에서 게이지50% 프리뷰를 시각적으로 확인하고 초기 숨김/0%로 복원했다.

실제 R 입력, 모바일, 온라인 다인전의 타이밍/음량/청취 체감은 미검증이다. 편집 프리뷰와 분리 검사를 실제 온라인 플레이 검증으로 간주하지 않는다.

## 백업과 복구

변경 전4개 소스(ClientHandler, ServerHandler, SniperScope, AmmoWarningStyle)를 양쪽 `ServerStorage.SniperCompressionBackup_20261011` 및 로컬 산출물에 보관했다. 새 공통 타이밍 모듈/게이지/완료·추가 발사 Sound는 별도 추가했다.

전체 복구 스크립트는 원본4소스와 이전 무지개 주기를 복원하고 새 객체를 제거한다. 이번 작업 후 전체 원복 실행은 하지 않았다. 이전 탄약 경고/강화탄 발사 후 재장전 보완은 유지한다.

공개 기록은 개발 문서만 포함한다. 게임 소스·원시 로그·플레이스 백업은 공개하지 않는다.
