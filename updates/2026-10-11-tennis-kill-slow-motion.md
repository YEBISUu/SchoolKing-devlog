# 2026-10-11 — 테니스 처치 직후 짧은 슬로모션

[현재 설정](../CURRENT.md) · [변경 기록](../CHANGELOG.md)

## 적용 범위와 동작

테니스 Studio 편집본에 적용했다. TGS·로비는 수정하지 않았다. 상대 플레이어 또는 연습 봇의 처치 기여가 확인되면 해당 라운드 참가자 두 명에게 같은 시작 시각을 전달한다. 낙사 등 공격자 없는 사망, 기권, 일반 피격에서는 시작하지 않는다.

- 처치 직후 총 0.65초: 처음 0.30초는 40% 속도, 다음 0.35초는 smoothstep으로 100% 복귀.
- 살아 있는 참가자는 기존 동시 사망 판정 구간 0.12초와 서버 종료 처리 동안 정상 속도를 유지한다. 라운드 전투 종료 후 남은 연출 시간에 이동·중력을 늦춘다.
- 사망 캐릭터는 기존 분해 충격이 적용된 뒤 몸체의 이동·회전 속도와 낙하를 늦춘다. 매 프레임 이전 배율 대비 비율로 조정해 속도가 계속 곱해져 멈추는 현상을 막았다.
- 클라이언트에서 참가자 애니메이션 재생 속도를 낮추고 복원한다. 마우스 시점 조작, HUD, 명중음/환호 재생 속도는 유지한다.
- 기존 결과 카메라 전환 시점(결과 시작 2초 후)과 라운드 점수·대기 시간은 유지한다.
- 전체 월드 시간을 바꾸는 기능은 아니다. 월드 중력, 장식·폭죽, 서버 타이머를 느리게 하지 않는다. 리프트·점프대·벽타기·그래플 등 별도 이동 제어 중에는 기존 이동 제어를 우선한다.

## 편집 위치와 설정

`ReplicatedStorage.TennisDuelConfig`:

| 설정 | 값 |
|---|---|
| KillSlowMotionEnabled | true |
| KillSlowMotionDuration | 0.65초 |
| KillSlowMotionScale | 0.4 |
| KillSlowMotionHold | 0.30초 |

연결 위치: `TennisDuelService`의 확인된 처치 처리, `GravityTrialController`의 플레이어 이동/중력 처리.

추가: `ReplicatedStorage.TennisKillSlowMotion`, `ServerScriptService.TennisKillSlowMotionService`, `StarterPlayerScripts.TennisKillSlowMotionClient`.

라운드 번호 불일치, Frozen, 캐릭터 제거, 시간 만료, 기능 비활성화 시 정상 배율로 돌아간다. 사망 파트에 임시 생성한 힘과 Attachment도 제거한다.

## 실제 검증

- 변경/추가 소스 6개 컴파일 및 최종 소스 대조 통과.
- 테니스 Studio Play에서 일반 서버 Script로 실제 연습 봇에 ShieldSystem 피해를 주고 사망·점수 처리를 실행했다. 실제 플레이어끼리의 온라인 대전 테스트는 아니다.
- 서버 15개 검사 통과: 배율 곡선/복귀, 확인된 처치 발동, 두 참가자의 시작 시각 일치, 동시 사망 구간 정상 배율, 사망 파트 제어/정리, 원래 월드 중력 유지, 라운드 종료·점수 증가.
- 클라이언트 130프레임 표본에서 6개 검사 통과: 동시 사망 구간 정상 이동, 결과 구간 WalkSpeed 16 → 6.4 → 16, 애니메이션 속도 1 → 0.4 → 1, 생존자 체력 유지.
- 상태 해제 6개 검사 통과: 사망 캐릭터 활성, Frozen 취소, 이전 라운드 무효, 기능 끄기, 만료, 제거된 캐릭터.
- 다음 라운드 Active 진입과 임시 슬로모션 힘 0개 확인. 총 27개 검사 통과.
- 확인한 콘솔 구간에 이번 변경 스크립트 오류 없음. 기존 맵 내부 HealthScript/RobloxTeam 오류와 별도 에셋 접근 경고는 이 작업에서 수정하지 않았다.

## 백업과 복구

수정 전 3개 기존 소스를 Studio `ServerStorage.TennisKillSlowMotionBackup_20261011`과 로컬 outputs의 `tennis-kill-slow-motion-20261011`에 보관했다. 추가 스크립트 목록 및 전체 원복용 `rollback.luau`도 로컬에 보관했다.

빠르게 끄려면 `KillSlowMotionEnabled=false`로 설정하고 새 Play/서버에서 확인한다. 전체 원복은 Play를 중지한 테니스 Studio에서 준비한 복구 명령을 사용한다. 공개 저장소에는 개발 문서만 올리고 소스·원시 로그·백업은 포함하지 않았다.

## 남은 확인

사용자가 느끼는 길이/강도, 실제 두 계정 PvP, 공중·슬라이딩 처치, 동시 처치/최종 라운드, 모바일에서의 체감은 추가 확인이 필요하다. Roblox 게시는 하지 않았으며 사용자가 진행한다.
