# 빈 탄창 자동 재장전 — 2026-10-11

[현재 설정](../CURRENT.md) · [변경 기록](../CHANGELOG.md)

## 동작

TGS와 테니스의 LegCrutch, Compass, Toaster, SiliconGun, Sniper에 적용했다.

1. 마지막 탄을 발사하면 추가 발사/R 입력 없이 재장전한다. 마지막 발사 간격과 진행 중인 발사 동작이 끝날 때까지 기다린다.
2. 빈 탄창인 무기를 다시 장착하면 장착 동작과 해당 무기의 서버 탄약 응답을 기다린 뒤 재장전한다.
3. 예비 탄약이0이면 자동 재장전 요청을 보내지 않는다.
4. 탄창에 탄이 남아 있으면 기존 R 재장전을 사용한다. 점사 종료 시 몇 발 남았다는 이유로 자동 재장전하던 경로도 빈 탄창 조건으로 통일했다.
5. 무기 교체는 기존처럼 즉시 가능하며 진행 중인 재장전을 취소한다. 취소된 재장전은 탄창이나 예비 탄약을 바꾸지 않는다.

스나이퍼 강화탄이 남아 있으면 그대로 보존하고, 발사해0발이 되면 일반 재장전을 시작한다. 실리콘건은 지속/스크럽 발사 자세가 끝나기를 무한히 기다리지 않도록 발사 간격을 기준으로 판단한다. 사망, 동결, 메뉴/결과 카메라, 테니스 비전투 상태, 무한 탄약에서는 자동 요청을 차단한다.

## 설정과 변경 범위

`ReplicatedStorage.GunSystem.GunConfig.Default.AutoReloadWhenEmpty=true`가 기본값이다. 특정 무기의 설정에서 같은 필드를 false로 지정하면 해당 무기의 자동 재장전을 끌 수 있다. 일반 R 재장전은 계속 가능하다.

- 공통 모듈 `GunSystem.AutoReload` 추가.
- 두 맵의 다섯 총기 ClientHandler에 조건 확인과 자동 요청 연결.
- 목발·컴퍼스·토스터 ServerHandler의 탄약 응답에 Tool 식별자 추가. 클라이언트에서 다른 무기의 응답을 무시한다.
- 목발·컴퍼스·토스터의 장착 타이머에 세션 검사를 추가했다. 이전 장착 콜백이 새 장착을 조기에 풀지 않는다.
- 같은 세 총기의 이전 재장전 완료 콜백이 새 탄창 표현을 복원하지 않도록 보호했다.
- 기존 서버 재장전/취소 및 탄약 소모 경로를 재사용한다. 스나이퍼·실리콘건 ServerHandler는 변경하지 않았다.

## 복구 및 게시

게임 수정 전에 두 맵 `ServerStorage.EmptyAutoReloadBackup_20261011`에 각각9개 원본을 복사했다. 로컬 outputs에도 수정 전/후 소스와 완전 원복 스크립트를 보관했다. 전체 원복 시 기존9개 소스를 복구하고 새 AutoReload 모듈을 제거한다.

Studio 편집본 적용을 완료했다. Roblox 게시는 수행하지 않았으며 사용자가 진행한다. 공개 저장소에는 개발 문서만 반영한다.
