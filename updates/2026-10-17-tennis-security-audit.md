# 2026-10-17 — 테니스 백도어 신고 정적 검사

## 결론

테니스 편집본의 의자 모델에서 외부 모듈을 간접 호출하는 의심 스크립트 `LightConfig` 1개와 하위 모듈 2개를 발견했다. 정밀 확인 도중 세 스크립트가 없어졌으며, 사용자가 전달한 다른 작업자의 삭제 보고와 스크립트 수 변화가 일치한다. 이번 검사자는 게임을 수정하거나 삭제하지 않았다.

현재 테니스 편집본의 재검색에서는 조사한 로더 패턴이 추가로 발견되지 않았다. 이는 검사 시점의 소스 검색 결과이며 게임 전체의 안전성, 게시본 정리, 과거 피해 부재를 보증하지 않는다.

## 직접 확인한 범위

- 대상: 통합 테니스 Studio의 Edit 데이터 모델. Play 또는 외부 모듈 실행 없이 소스와 인스턴스 정보를 읽었다.
- 최초 소스 컨테이너 8,476개, 길이·Adler32 기준 449개 소스 그룹. 소스 읽기 실패 0개.
- 의심 경로: `Workspace.Model.Table.table_chair.Model.Part.Part-to-Part Strong Joint.LightConfig`.
- 최초 검색에서 하위 `Type` 모듈 호출과 `EasyConfiguration`의 `Pose.Value`를 사용하는 간접 require 호출을 확인했다. 상위 스크립트는 활성 상태였다.
- 이후 소스 컨테이너 8,473개. 문자열 자체로 중복을 구분하면 446개 소스. 같은 이름·호출 패턴은 현재 편집본에 남아 있지 않았다.
- 현재 소스의 require 호출과 HTTP/동적 실행/에셋 로딩/난독화 단서를 검색했다. 남은 호출 중 검토한 항목은 게임 내부 모듈과 PlayerModule, 로비용 MemoryStore 처리였다.
- 추가 확인한 LightConfig 계열 및 전달받은 Retsatrophe/PoseLink 계열 식별 문자열은 검색 0건. LinkedSource 비어 있지 않은 항목 0개, PackageLink 0개. 이 검색은 이름을 바꾸거나 다른 방식으로 숨긴 모든 코드를 판별하는 증명은 아니다.
- HttpEnabled=false를 확인했다. 이 값만으로 외부 모듈 실행이 불가능하다고 판단하지 않았다. LoadStringEnabled는 이번 검사에서 확인하지 못했다.

## 기존 보관본과의 대조

10월 2일 보관된 TGS 책 뷰모델의 LightConfig/Type/EasyConfiguration 소스가 최초 테니스 검색의 세 스크립트와 각각 길이 및 Adler32가 일치했다. 이는 대조 근거이며 삭제 전 전체 소스를 암호학적으로 동일 비교한 것은 아니다.

이 보관본을 실행하지 않고 읽었을 때, 에셋 설명을 숫자로 바꾸어 외부 모듈 실행 대상으로 사용하고 JobId에 따라 후속 실행을 건너뛰는 구조가 있었다. 일반 조명 설정과 무관한 로더 패턴으로 판단한다. 주석에 적힌 기존 라이브러리 저자명이 실제 삽입자의 신원이라는 증거는 없다.

테니스의 Pose 값·외부 모듈 번호는 삭제 전에 확보하지 못했다. 외부 코드의 실제 내용, 성공적으로 실행되었는지, 누가 언제 삽입했는지는 확정하지 않았다.

Roblox의 require는 모듈을 실행하며 에셋 번호를 받을 수 있다. [공식 require 문서](https://create.roblox.com/docs/reference/engine/globals/LuaGlobals#require).

## 다른 작업자의 보고 — 별도 출처

사용자가 전달한 메시지 기준으로 로비 정리 완료, 테니스 의자 로더 삭제 완료, TGS 의심 항목 46개는 권한 검토에서 막혀 미삭제 상태라고 한다. TGS 책 뷰모델 원본·복제용 보관본도 포함된다는 보고가 있다.

이번 검사에서 직접 대조한 것은 테니스의 삭제 전후 소스 수와 해당 경로 소멸이다. 로비의 안전 여부와 TGS 46개의 목록·활성 여부·삭제 상태는 이 세션에서 독립적으로 확인하지 않았다. 다른 작업자에게 발생한 권한 검토 결과를 이번 검사자의 도구 실행 결과로 기록하지 않는다.

## 검사 한계와 다음 조치

- 7,510개 소스가 주석 한 줄 `-- Decompiling is disabled`만 가지고 있었다. 현재 보이는 소스에는 실행문이 없지만 이 문구만으로 원래 내용·과거 동작·모든 실행 상태가 무해했다고 단정하지 않는다.
- 설치 플러그인, 계정 접근, Team Create 변경 주체, Roblox 게시 버전, 이미 실행 중인 온라인 서버는 미검사.
- TGS 정리 상태 확인과 외부 코드 실행 경로 제거는 별도 후속 작업이다. 과거 백업을 복구할 때도 동일 로더의 재유입 여부를 확인해야 한다.
- 삭제 사실과 게시 반영은 별개다. Roblox 게시는 사용자가 진행하며 이번 검사자는 게시하지 않았다.
- 로컬에 검색 근거와 보관본 분석 자료를 저장했다. 원시 로그·게임 소스·백업·개인 경로는 공개 저장소에 올리지 않았다.
