# 피격 이펙트 대비·헤드샷 색·막타 피해 숫자

2026-10-11 · 적용 대상: TGS·테니스 Studio 편집본. Roblox 게시는 수행하지 않았다.

## 최종 표시 규칙

| 상황 | 몸에서 나오는 피격 이펙트 | 개별 피해 숫자 | 누적 피해 숫자 |
|---|---|---|---|
| 실드 없는 일반 몸통 명중 | 진한 주황 | 기존 흰색(사지 회색) | 기존 흰색/최근 헤드샷 강조 |
| 실드 없는 일반 헤드샷 | 빨강 | 기존 노랑 | 기존 노랑 강조 후 흰색 복귀 |
| 처치한 막타 | 위의 부위 규칙 유지 | 빨강 | 처치한 대상의 합계 빨강 |
| 실드 명중/파괴 | 기존 실드 효과 | 기존 부위색, 막타만 빨강 우선 | 동일 |

사용자 최종 요청은 “머리 이펙트 빨강, 일반 헤드샷 숫자는 유지, 막타 숫자 빨강”이다. 몸통 막타의 이펙트를 빨강으로 바꾸는 규칙은 적용하지 않았다. 기존 빨간 처치 마커와 헤드샷 노랑 숫자 연출도 유지한다.

## 이펙트 최종 값

두 맵의 `ReplicatedStorage.HealthImpactTemplates` 1~3번 Hit1:
- LightEmission: 1 → **0.15**.
- Brightness: 2 → **1.8**.
- 일반 체력 피격 Color: RGB255/90/20 → RGB235/40/10.
- Transparency: 시작0, 수명65%까지0, 끝1.
- 머리 체력 피격은 복제된 이펙트에만 RGB255/35/35 → RGB210/10/20을 적용한다. 공통 원본 템플릿은 주황 유지.
- 텍스처·입자 크기·수명0.5초·BurstCount1·재생 방식 등 나머지17개 속성 보존. 호스트 정리0.6초 유지.

사전 조사에서 제안한 0.3/1.2는 최종 값이 아니다. 편집 화면의 밝고 어두운 배경 비교 후 위 값으로 조정했다. 샘플 프레임에서 주황 대비 증가와 직사각형 텍스처 바탕이 드러나지 않는 모습을 확인했다. 임시 프리뷰를 제거하고 카메라를 원래 상태로 복구했다.

## 서버·표시 연결

- 다섯 총기의 서버 명중 판정에서 확정 헤드샷 여부를 ShieldSystem → DamageFlashEvent → DamageFeedback → ShieldImpactVFX로 전달한다.
- 스나이퍼 보조 판정은 기존 confirmedHead를 사용한다. 보조 영역만 Head에 걸린 경우를 새 헤드샷으로 승격하지 않는다. 실리콘 레이저의 기존 비헤드샷 규칙도 유지한다.
- 가까운 시간·위치의 입자 중복 억제에서 머리/몸통을 구분해 몸통 입자가 직후 머리의 빨간 입자를 지우지 않게 한다. 동일 머리 입자 중복 억제는 유지한다.
- ShieldSystem은 실제 HP가 양수에서0 이하로 내려간 호출에만 막타 결과를 반환한다. 피해량·배율·실드 흡수·킬 귀속 계산은 유지한다.
- 기존 피해 숫자를 보내는 총기·근접·CAN/Cup·GrenadeCore 경로에 해당 호출의 막타 결과와 대상별 식별자를 추가했다. 실드 전용 토스터 화상은 같은 식별자를 사용하고 막타는 false다.
- 대상 식별자는 서버 약한 참조 캐시에 보관한다. 클라이언트에 캐릭터가 늦게 복제되거나 삭제되어도 문자열 ID로 합계를 구분한다.
- 가까이 붙은 다른 적의 피해를 합치지 않는다. 같은 대상은 기존0.9초 합산 창을 유지하며, 처치한 합계는 이후 다른 명중과 합치지 않는다.
- 막타 개별·합산 숫자 RGB255/60/60. 합계는 사라질 때까지 빨강 유지. 일반 헤드샷 숫자 RGB255/220/80, 합산0.35초 노랑 유지+0.15초 흰색 복귀는 그대로다.
- 기존 CAN ServerHandler의 플레이어 장판 피드백에서 정의되지 않은 prim 대신 해당 분기의 hrp 위치를 사용하도록 보완했다.

## 검증과 한계

- 격리된 실제 후보 코드 실행 **50개 검사 통과**: 숫자16, 입자9, 테니스 피해 처리13, TGS 피해 처리12.
- 숫자: 일반 몸통/머리, 몸통·머리 막타, 근접한 여러 대상, 빠르게 이동한 같은 대상 합산, 다음 적의 색, 처치 마커 우선순위, 스나이퍼 비확정 헤드, 수명 종료 정리.
- 입자: 머리 빨강/몸통 주황, 세 변형, 원본 템플릿 불변, 몸통→머리 연속 명중, 동일 머리 중복 억제, 실드 명중·파괴 색 보존.
- 서버: 안정적인 대상 ID, 일반 명중과 실제 막타 구분, 헤드 정보 전파, 실드 흡수·초과 피해, 무적·피해 차단 및 테니스 비전투 거절.
- 최종 Studio **28개 소스** 컴파일·적용 내용·수정 전 백업 대조 통과. 두 맵6개 입자 최종 속성 재확인.
- 테스트는 실제 플레이어에게 가짜 이벤트를 보내지 않고 별도 객체·모의 이벤트로 수행했다. TGS 테스트의 CrownCombat 의존성 모의 누락과 속성 비교의 부동소수점 허용오차를 테스트에서 보완한 뒤 통과했다.
- 새 Play 세션, 실제 입력, 온라인 다인전, 모바일, 모든 투척물/근접 경로의 종단 간 실행은 이번에 확인하지 않았다. 입자 색·숫자의 실제 전투 시인성과 관통/산탄 동시 명중은 사용자 실플레이 확인이 남는다.

## 편집·복구

- 머리 이펙트 색: `ReplicatedStorage.ShieldImpactVFX.HEAD_HIT_COLOR`.
- 막타 숫자 색: `StarterPlayerScripts.DamageNumbers.KILL_RED` (기존 처치 마커와 공통).
