# 2026-10-11 — TGS 종료 후 텔레포트 오류 769 조사

## 신고와 확인 범위

사용자는 TGS 경기 종료 후 로비 복귀 중 Roblox 기본 팝업 '텔레포트 실패, 오류 코드 769'가 표시되었다고 확인했다. 스크린샷, 최근 Roblox 앱 실행 기록, TGS Studio 편집본의 이동 코드를 읽었다. 이번 작업에서는 게임 코드·설정·명중 보정을 변경하거나 Roblox에 게시하지 않았다.

## 실행 기록에서 확인한 내용

- 해당 실행에서 TGS 입장과 TravelArrival 준비 완료를 확인했다.
- 2026-10-11 02:30:26 UTC (한국/일본 11:30:26), TeleportInitFailed와 Enum.TeleportResult.Failure가 기록되었다.
- 구체적인 메시지는 텔레포트 과정의 HTTP 오류를 알리고 클라이언트를 닫은 뒤 다시 시도하도록 안내한다.
- 같은 실행 기록에서 약 14초 후 텔레포트 완료와 로비 Place 접속 기록을 확인했다.
- 그 뒤 로비에서 테니스로 이동한 기록도 있다.

따라서 이번 기록에서는 복귀 요청 실패 뒤 로비 접속이 성립했다. 사용자가 수동 재시도를 눌렀는지, 서버 자동 재시도가 성공했는지는 클라이언트 기록만으로 구분하지 않는다. 로비 접속 기록은 UI의 모든 요소가 정상 복구되었다는 증거도 아니다.

원시 로그, 사용자·세션 식별자, 네트워크 주소, 인증/예약 서버 정보는 공개 문서에 포함하지 않았다.

## 현재 편집본 코드 확인

- TGS의 로비 목적지는 IntegrationConfig.LobbyPlaceId이며, 실행 기록의 도착 장소와 일치한다.
- 실제 활성 이동 서버는 ModeTravelServer. 예전 MatchmakingService는 Disabled 상태여서 편집본에서 두 이동 서버가 동시에 동작한다고 볼 근거는 없다.
- TravelService에는 최초 요청을 포함한 최대 3회 시도, 1.5초/3초 재시도 대기, 60초 미완료 잠금 해제가 이미 있다.
- TeleportInitFailed에서 목적지와 TravelAttemptId가 일치하는 요청만 재시도한다. Roblox가 전달한 재시도 TeleportOptions를 보존한다.
- 최종 실패 시 returnError와 게임 내 재시도 버튼을 표시하는 경로가 있다.
- 게시 서버가 현재 편집본과 완전히 같은 버전인지는 별도 확인하지 않았다.

## 결론과 미확인 항목

확인된 직접 실패는 이동 요청의 HTTP 오류이다. HTTP 오류를 유발한 플랫폼·네트워크의 하위 원인은 현재 자료로 특정할 수 없다. 화면의 769 숫자만으로 권한 문제나 잘못된 Place ID로 단정하지 않는다.

이번 사건과 명중 보정 사이의 인과관계는 확인되지 않았다. 되감기 판정 모듈은 이동 호출 경로를 변경하지 않는다. 이번 조사 때문에 명중 보정을 원복하거나 재시도 횟수를 임의로 늘리지는 않았다.

반복 발생 여부, 자동/수동 재시도 구분, 서버 쪽 실패 상세, 최종 실패 후 재시도 버튼 사용성, 파티 전체 복귀는 미확인이다. 이전 복귀 관련 버그 전체를 해결 상태로 닫지 않는다.

## 공식 근거

Roblox는 TeleportAsync 호출이 시작된 뒤에도 나중에 실패할 수 있으며, TeleportInitFailed 처리와 제한된 재시도를 안내한다. 이 일반 동작은 이번 오류의 하위 원인을 확정하는 자료는 아니다.
