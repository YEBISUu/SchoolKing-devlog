# 2026-10-11 스코프 중 전투 HUD 표시

[현재 설정](../CURRENT.md)

## 요청과 원인

스나이퍼 스코프 중에도 체력, 수류탄 개수, 회복 아이템 개수, 장비칸, 중앙 잔탄을 표시하도록 요청했다.

스코프 ScreenGui의 DisplayOrder180이 GameHUD0 위에 있어 원형 시야 밖의 검은 마스크가 HUD를 덮었다. 중앙 잔탄은 SniperScope에서 Enabled=false로 숨기고, GunUIController도 스코프가 켜져 있으면 매 프레임 다시 숨겼다.

## 적용

TGS·테니스 Studio 편집본에 동일한 동작을 적용했다.

- ReplicatedStorage.GunSystem.SniperScope: DisplayOrder=-1로 전투 HUD 아래에 표시. CrosshairAmmoHUD 숨김 제거. GameHUD/GunUI의 일반 조준점만 숨기고 해제 시 원래 상태 복원.
- StarterGui.GunUI.GunUIController: 스코프 여부로 잔탄 아크를 끄던 조건 제거. 기존 서버 탄약 이벤트·무기별 캐시·화면 중앙 좌표와 반경 사용.
- 일반 조준점 숨김은 스코프 렌더 단계에서도 유지하여 다른 HUD 갱신 뒤 십자선이 겹치지 않게 했다.
- 체력·실드, 수류탄/회복 슬롯, 장비칸의 기존 크기·위치·이미지·갱신 경로 유지. 중앙 잔탄은 기존 아크 형식을 사용하며 새 숫자 UI를 추가하지 않았다.
- 로비·메뉴·사망·관전·Frozen의 기존 표시 제한 유지. HUD를 무조건 켜는 방식은 사용하지 않았다.
- 본인 손/무기 숨김,1~4배·마지막 배율 기억, 강화된 반동과 명중음은 변경하지 않았다.

## 검증

양쪽 두 소스를 컴파일하고 최종 준비본과 대조했다. 테니스 Play에서는 정상 LocalScript에서 실제 스코프 모듈·HUD 컨트롤러를 사용하고 임시 서버 이벤트로 값 갱신을 주입해16개 확인 항목을 통과했다.

- 1배와4배 스코프 Visible/Enabled 확인.
- 체력 패널·장비칸·수류탄·회복 슬롯의 부모까지 표시 상태 확인.
- HUD와 중앙 잔탄 DisplayOrder0이 스코프-1 위에 있는지 확인.
- 스나이퍼 탄창5칸 아크 표시, 일반 조준점 숨김 및 다른 HUD가 켜려 할 때 중복 방지.
- 스코프 중 회복3→2, 수류탄2→1, 탄창5→3/예비30→25 및 중앙 활성 잔탄5→3 갱신.
- 스코프 해제 뒤 HUD/잔탄 유지와 일반 조준점 복구.
- 메뉴 진입 시 스코프·중앙 잔탄의 기존 숨김 유지.

이는 Studio 단일 클라이언트의 표시 속성·그리기 순서·이벤트 갱신 검사다. 실제 사용자 조작, 모든 해상도/모바일 배치, 온라인 다인 경기의 전 과정을 재검증한 것은 아니다. 실제 사격/아이템 소비 대신 서버 값 갱신을 주입했으며, 소비 로직 검증과 구분한다. 시험용 코드와 임시 상태는 Play 종료로 제거했다.

## 백업과 게시

변경 전 두 소스를 양쪽 ServerStorage.SniperScopeHUDBackup_20261011과 로컬 outputs에 보관했다. 해당 폴더의 RollbackCommand는 Play를 중지한 Edit에서 두 원본 소스를 복원한다. 이번 작업에서 복구 명령 자체를 실행하지는 않았다.

Roblox는 게시하지 않았다. GitHub에는 개발 문서만 공개하며 게임 소스·원시 로그·플레이스 백업은 포함하지 않는다.
